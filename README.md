# ThermStack website

Product overview and white papers for ThermStack, thermal analysis for 2.5D and 3D chiplet design.

- `whitepapers/`: the WP-1xx white-paper series.

Static HTML, CSS and JavaScript. Open `index.html` in a browser; no build step is needed.
